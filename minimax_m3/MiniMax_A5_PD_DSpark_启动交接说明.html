2. 如何查 DSpark 采信率

从两个后端的 Prometheus /metrics 读取累计计数。可使用本轮目录内的只读解析器 dspark_metrics.py。P 和 D 的所有 DP 标签都要汇总；代理 8009 不是这些推理指标的来源。

# 在 26 宿主机查看原始指标
curl --noproxy '*' -fsS http://197.13.50.1:31050/metrics |   rg '^vllm:spec_decode_num_(drafts|draft_tokens|accepted_tokens)_total'
curl --noproxy '*' -fsS http://197.13.51.1:31060/metrics |   rg '^vllm:spec_decode_num_(drafts|draft_tokens|accepted_tokens)_total'
指标含义
spec_decode_num_drafts_total草稿验证轮次
spec_decode_num_draft_tokens_total草稿模型提出的 token 总数
spec_decode_num_accepted_tokens_total被主模型接受的草稿 token 总数

Token 采信率 = 接受的草稿 token / 提出的草稿 token。一段时间的采信率应使用两次快照之差：Δaccepted / Δdraft_tokens。不要直接平均不同 DP 的百分比。服务重启会重置计数，跨重启的差值无效。

下面命令在 26 取 30 秒窗口，汇总两台各 DP 指标，不会提交推理请求：

python3 - <<'PY'
import json, time, urllib.request
opener = urllib.request.build_opener(urllib.request.ProxyHandler({}))
names = ['spec_decode_num_drafts_total', 'spec_decode_num_draft_tokens_total',
         'spec_decode_num_accepted_tokens_total']
def snapshot():
    out = dict.fromkeys(names, 0.0)
    for url in ['http://197.13.50.1:31050/metrics', 'http://197.13.51.1:31060/metrics']:
        with opener.open(url, timeout=10) as response:
            text = response.read().decode()
        for row in text.split('
'):
            if not row or row.startswith('#'):
                continue
            metric = row.split('{', 1)[0].split(' ', 1)[0]
            for name in names:
                if metric.endswith(name):
                    out[name] += float(row.split()[-1])
    return out
before = snapshot()
time.sleep(30)
after = snapshot()
delta = {name: after[name] - before[name] for name in names}
if any(value < 0 for value in delta.values()):
    raise SystemExit('计数出现重置；检查服务是否重启，本窗口不能计算采信率。')
draft = delta['spec_decode_num_draft_tokens_total']
accepted = delta['spec_decode_num_accepted_tokens_total']
rounds = delta['spec_decode_num_drafts_total']
print(json.dumps({'window_seconds': 30, 'deltas': delta,
                  'token_acceptance_rate': accepted / draft if draft else None,
                  'accepted_draft_tokens_per_round': accepted / rounds if rounds else None},
                 ensure_ascii=False, indent=2))
PY
