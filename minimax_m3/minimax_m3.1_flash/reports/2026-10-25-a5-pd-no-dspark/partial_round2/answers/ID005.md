I should present step-by-step reasoning.</think>## Setting up

The operator $\vec P$ is the spin-1/2 (Pauli) operator:

$$\vec P = \frac{\hbar}{2}\left(\sigma_x \hat x + \sigma_y \hat y + \sigma_z \hat z\right)$$

For a direction $\vec n$ in the x–z plane, $\vec n = (\sin\theta,\, 0,\, \cos\theta)$, so we need the eigenvector of:

$$P_{\vec n} = \vec P\cdot\vec n = \frac{\hbar}{2}\left(\sin\theta\,\sigma_x + \cos\theta\,\sigma_z\right) = \frac{\hbar}{2}\begin{pmatrix}\cos\theta & \sin\theta\\ \sin\theta & -\cos\theta\end{pmatrix}$$

## Solving the eigenvalue equation

Let $|\psi\rangle = \begin{pmatrix} a\\ b\end{pmatrix}$ with $P_{\vec n}|\psi\rangle = +\frac{\hbar}{2}|\psi\rangle$:

$$\begin{pmatrix}\cos\theta & \sin\theta\\ \sin\theta & -\cos\theta\end{pmatrix}\begin{pmatrix}a\\b\end{pmatrix} = \begin{pmatrix}a\\b\end{pmatrix}$$

From the first row: $\cos\theta\, a + \sin\theta\, b = a \Rightarrow \sin\theta\, b = (1-\cos\theta)\,a$

$$b = \frac{1-\cos\theta}{\sin\theta}a = \tan\!\left(\frac{\theta}{2}\right)a$$

## Normalizing

With $a = \cos(\theta/2)$, $b = \sin(\theta/2)$, we get $\cos^2(\theta/2)+\sin^2(\theta/2) = 1$ ✓

**Check:** applying the matrix to $(\cos(\theta/2), \sin(\theta/2))$:

- Row 1: $\cos\theta\cos(\theta/2)+\sin\theta\sin(\theta/2) = \cos(\theta/2)$ ✓
- Row 2: $\sin\theta\cos(\theta/2)-\cos\theta\sin(\theta/2) = \sin(\theta/2)$ ✓

Both reproduce the vector with eigenvalue $+\hbar/2$.

The normalized eigenvector is:

$$|\psi\rangle = \begin{pmatrix}\cos(\theta/2)\\ \sin(\theta/2)\end{pmatrix}$$

Note that the components of a spin-1/2 eigenvector are dimensionless amplitudes (not multiplied by $\hbar$), and since $\vec n$ lies in the x–z plane there is no phase factor $e^{i\phi}$ (ruling out C, which corresponds to a general direction with azimuthal angle $\phi$).
