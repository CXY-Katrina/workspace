# PPT格式要求
## 品牌色规范
生成 PPT 时严格遵循以下配色：

| 颜色 | HEX | 用途 |

|------|-----|------|

| 主色红 | #D33941 | 关键数据、重点结论、强调标签、标题下划线 |

| 深红 | #D33859 | 重要风险、战略主题 |

| 浅红变体1 | #E18189 | 次级强调、浅色背景 |

| 浅红变体2 | #EFB2B8 | 弱强调背景、图表浅色区块 |

| 深灰 | #555757 | 正文、分类标题、图表轴线 |

| 中灰 | #898989 | 注释、来源、次级说明 |

| 极浅灰 | #DDDDDD | 卡片边框、表格线 |

| 白色 | #FFFFFF | 主背景、卡片背景 |

辅助色（图表用）：

洋红 #C40054 — 市场、用户、增长

深红 #7F0001 — 风险、预警、负向指标

橙色 #ED6D00 — 机会、趋势、进展

黄色 #FDD351 — 提示、待关注

绿色 #62B230 — 正向增长、完成

青色 #30B5C5 — 技术、平台、系统

图表数据系列配色顺序：#D33941 → #555757 → #30B5C5 → #62B230 → #ED6D00 → #FDD351

## 字体规范
中文字体：微软雅黑 / Microsoft YaHei

英文字体：Arial

数字字体：Arial

字号层级：

页面主标题：28pt

分项标题：16-20pt 加粗

关键数字：28-36pt 加粗

正文说明：11-14pt

标签文字：10-12pt

注释来源：6-9pt 斜体灰色

## 页面布局规范
页面比例：16:9（13.333 x 7.5 英寸）

标题区：页面顶部左侧，左边距约 6%，字号 28pt，下��品��红细线

内容区：页面中部，每页 3-6 个核心信息组

注释区：页面底部，6-9pt 灰色斜体

## 文字表达规范
标题直接表达结论，不使用泛泛描述（如"业务情况介绍"）

每个信息点控制在 15-30 字

避免长段落，使用短句、动宾结构

关键数字红色，单位灰色
